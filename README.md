# 🧮 Simple Calculator
## About
A beginner-friendly Simple Calculator built using Python 🐍

A simple command-line calculator that performs basic mathematical operations such as Addition, Subtraction, Multiplication, and Division.

## ✨ Features 
➕ Addition
➖ Subtraction
✖️ Multiplication
➗ Division
🔢 Accepts numbers from the user
🛡️ Handles division by zero
⚠️ Handles invalid operators
💻 Runs directly in the terminal

### *🚀 How to Run**

Terminal → New Terminal

3️⃣ Run the Program
python simplecalulator.py

🎯 How It Works

The program asks the user for:

First number
Mathematical operator
Second number

Then it calculates and displays the result.

## Example:

Enter first number: 20

Enter operator (+, -, *, /): *

Enter second number: 5

Result: 100.0

🧪 Supported Operations
Operator	Operation	Example
+	Addition	10 + 5 = 15
-	Subtraction	10 - 5 = 5
*	Multiplication	10 * 5 = 50
/	Division	10 / 5 = 2
🛡️ Error Handling

The calculator also handles common errors.

Division by Zero
Enter first number: 10
Enter operator (+, -, *, /): /
Enter second number: 0

Result: Cannot divide by zero

Invalid Operator
Enter first number: 10
Enter operator (+, -, *, /): %
Enter second number: 5

Result: Invalid operator
