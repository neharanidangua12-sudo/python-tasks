Python Calculator

A simple calculator application built using Python. It performs basic arithmetic operations such as addition, subtraction, multiplication, and division.

Features:
Addition (+)
Subtraction (-)
Multiplication (*)
Division (/)
Handles division by zero
Takes user input from the terminal
Requirements
Python 3.x

No external libraries are required.

How to Run
Clone or download this project.
Open a terminal in the project directory.
Run the Python file:
python calculator.py


On some systems, you may need to use:

python3 calculator.py

Example
Enter first number: 20
Enter operator (+, -, *, /): +
Enter second number: 10

Result: 30.0

Error Handling

The calculator displays an error message if:

An invalid operator is entered.
The user attempts to divide by zero.
